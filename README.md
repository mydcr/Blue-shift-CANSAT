# CanSat Outreach Website

A responsive starter website built with HTML, CSS and JavaScript for a student CanSat team.

## Preview locally
Open `index.html` in a browser. No build tools are required.

## Publish with GitHub Pages
1. Create a GitHub account (or sign in).
2. Create a new **public** repository, e.g. `cansat-outreach`.
3. Upload `index.html`, `styles.css`, `script.js`, and this README to the repository root.
4. In the repository, open **Settings → Pages**.
5. Under the build/deployment section, choose **Deploy from a branch**.
6. Select branch `main` and folder `/ (root)`, then save.
7. Wait for GitHub Pages to publish the site. The URL appears in the Pages settings.

## Edit the site
- Page content and placeholder profiles: `index.html`
- Colours, layout and responsive design: `styles.css`
- Mobile menu and progress filters: `script.js`

## Before publishing
- Replace `YOUR TEAM NAME` and all sample team profiles.
- Replace the sample mission descriptions with your actual chosen missions.
- Replace sample progress entries and `ADD DATE` with genuine updates.
- Replace social links and `REPLACE_WITH_TEAM_EMAIL`.
- Update outreach statistics only with real evidence.
- Ask permission before publishing identifiable photos or personal information about team members; follow school and competition safeguarding rules.
- Check all competition-specific descriptions against the current rules.
